## Размещение на GitHub Pages

1. Войдите в GitHub и создайте публичный репозиторий. Для адреса `https://USERNAME.github.io/` назовите его `USERNAME.github.io`, подставив своё имя пользователя. Если такой сайт уже используется для карьеры, создайте отдельный репозиторий, например `writing`: адрес будет `https://USERNAME.github.io/writing/`.
2. Загрузите **содержимое** этой папки в корень репозитория: `index.html`, `styles.css`, папку `assets`, `.nojekyll` и при желании README. Не загружайте ZIP вместо файлов. В веб-интерфейсе GitHub используйте Add file → Upload files. Скрытый `.nojekyll` при необходимости создайте через Add file → Create new file; файл пустой, нужен только его заголовок-имя.
3. Сохраните файлы в ветке `main`.
4. Откройте Settings → Pages. В Build and deployment выберите Source: **Deploy from a branch**, Branch: **main**, папка **/(root)**, затем Save.
5. Дождитесь успешного развёртывания. Фактическую ссылку откройте через **Visit site** в Settings → Pages. Публикация может занять несколько минут.

Ссылки на ресурсы относительные, поэтому сайт работает и в корне домена, и в подпапке репозитория. Свой домен не требуется. `.nojekyll` отключает обработку Jekyll.

Официальная инструкция: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## Индексация

Включены английский язык страницы, title, description и семантические разделы. Canonical и sitemap стоит добавить после получения реального публичного адреса; сейчас адрес не выдуман. Появление в поиске и сроки индексации не гарантируются. После публикации можно отправить фактический адрес в Google Search Console.

Раздел News содержит короткие авторские заметки на английском. Первая — о завершении A Hundred Years Away, датирована 12 ноября 2026 по указанию автора «вчера» (дата запроса — 13 ноября 2026, America/Chicago). Это сообщение о завершении работы, а не о публикации рассказа.

Также добавлена заметка о завершении The Price of Expansion с явной пометкой Unpublished. Дата завершения автором не указана, поэтому у этой заметки даты нет. Порядок заметок отражает порядок добавления, а не неподтверждённую хронологию завершения рассказов.

Добавлена заметка о завершении Where Did Weil Go? без даты: автор подтвердил завершение, но не указал дату или статус публикации.

Чтобы добавить новость, вставьте новый `article` с классом `news-entry` в начало содержимого News, задайте уникальный `id` заголовку и укажите его в `aria-labelledby`. При известной дате используйте `<time class="news-date" datetime="2026-11-12">November 12, 2026</time>`, подставив фактическую дату. Частоту обновлений сайт не обещает.
